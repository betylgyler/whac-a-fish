# 🎣 Whac-a-Fish

A browser-based game developed as part of a university course.

## About

Whac-a-Fish is an interactive game where the player catches fish to earn points. The project was built to practice JavaScript programming, event handling, and web development fundamentals.

## Technologies

- HTML5
- CSS3
- JavaScript

## What I Learned

- Manipulating the DOM
- Handling user interactions
- Organizing JavaScript code
- Building an interactive web application
